# Morse Keyboard

Bill Mandel's Radio Shack Color Computer Morse code program, running from its original 6809 code in the browser.

Play: open `dist/morse_keyboard.html` (one self-contained file, works from disk or any static server).
The only external request is the Google Fonts stylesheet; without it the page falls back to system fonts.

Rebuild and check: `make` (needs python3 and node).

See `CLAUDE.md` for layout, what was verified, and the quirks of the original program.
