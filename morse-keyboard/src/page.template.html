Morse Keyboard

A Radio Shack Color Computer program by Bill Mandel, rebuilt from a fanfold printout. The original 6809 program runs here in an emulator: type text and it sends Morse, or let it listen and decode. Play it a recording of real on-air CW and watch it learn the timing.

Quick start

  1. Click the screen, press S.
  2. Type a speed in words per minute, such as 20, then Enter.
  3. Press Up arrow for transmit mode. Type a message, then Enter to send it.
  4. Press Down arrow for receive mode, then use Station B or the key below.

Program

As printed only decodes this program's own sending rhythm. The patched version changes two receive-side calculations, the letter-gap threshold and the word-gap timeout, so ordinary Morse spacing works. Sending is identical. Changing version restarts the program.

Station B

A second Color Computer running the same program. Its key line is wired to your cassette input.

Put your station in receive mode first.

Recording

Play an mp3, aac, ogg or wav of Morse into your receiver. Put your station in receive mode and set a speed first. The patched receiver read a real on-air ragchew (Italian, 7036 kHz) at 16 to 36 WPM. As printed, the program only decodes its own sending rhythm, so the same recording comes out as E and T.

The 1942 course is five-character groups of letters and digits, sent by hand at about 20 WPM. It is from archive.org, a U.S. government work and likely public domain, though the item itself carries no rights mark. Your browser fetches it straight from archive.org when you click.

Straight key

Or hold Ctrl. This drives the same input as Station B. The patched receiver copes with ordinary spacing. As printed, the receiver expects the short gaps this program sends itself, so a hand key needs tight spacing inside each letter.

About

The 2,338 bytes at $3462 to $3D83 are assembled from the printed listing and checked against its object code, byte for byte. As printed, they run unmodified. The patched version changes two receive-side calculations (16 lines differ) and is the default here.

The program times everything by counting loop passes, and each pass includes Color BASIC's keyboard routine. That routine is replaced by a stand-in timed so a dit lasts 1.2 / WPM seconds. The real cost is inferred, not known.

The program's first received letter is used up learning dit and dah lengths, and it learns once per run. Station B sends a leading V for that reason. Sending a recording after a pause works the same way. Watch the top-left corner of the screen: it starts flashing yellow and blue once the dit and dah lengths are learned and tones are being timed.
